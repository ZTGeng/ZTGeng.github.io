## 定位与内容

- 在个人网站 `/geb/` 下，以互动网页展示《Gödel, Escher, Bach》中的有趣内容。
- 用户有中文版原书，也可以使用来源与授权明确的网络素材。
- 这是受书中内容启发的互动项目，不是原书网页版，不复刻整本书。
- 按原书章节组织，各章通过 HTML5 游戏、应用或可操纵的演示展示观点。
- 尽量减少文字阅读：先操作，再用少量文字点明发现，深入解释按需展开。
- 具体中文章节名与符号采用用户持有版本核对，由用户最终确定。
- 每个互动围绕一个明确发现设计。

## 页面架构

- 使用多页面架构：项目首页负责章节入口，每章拥有独立目录和 `index.html`。

- 跨章节进度和用户设置按需使用 `localStorage`；确需跨章延续的体验另行设计状态传递。

## 首页木雕（已实现）

- 按用户要求仅在 `/geb/` 内引入 Vite（6.4.5，兼容本地 Node.js 20）和 Three.js（0.186.1），均锁定版本；没有 React、后端、外部 API 或运行时 CDN。
- 深色首页保留姓名、中文介绍、下一章链接和页脚；中央为暖木雕及两面墙、一块地面的真实三路阴影，初始为左墙 G、右墙 E、地面 B。
- 固定几何来自 `G(-z,y) ∧ E(x,y) ∧ B(x,-z)`，使用自制粗笔画轮廓的 96³ 体素交集及共面矩形合并；一个六邻接连通体，1,696 个三角形。三个采样正交轮廓覆盖率均为 100%；导出三角形另有独立投影测试。
- 模型在 `scripts/generate-geometry.js` 中离线生成，位于 `assets/model/sculpture.json`。`projection-*.svg` 仅供诊断，页面不加载。渲染使用固定网格、原生 PCF 阴影与局部坐标木纹，不使用字母贴图或模拟阴影。
- 接影面已从 x/y/z=-3.15 外移至 -4.4，调整固定相机构图，避免木雕遮住初始字母；回归测试检查桌面和窄屏相机到三字形采样点的视线均不被木雕阻挡。
- 三盏轴向 DirectionalLight 由正轴照向原点。正交关系使每个接影面只受到对应光的漫反射，无额外合成通道。`src/home/receiver.js` 在黑墙上模拟圆形入射光范围，参考用户提供的原书封面。用户手调后参数为渐变起点 0.50、终点 8.0、额外衰减系数 1.0，归一化分母 64.0=8²；在距离中心 4.4 的墙面交界仍保留约 33% 直接光，使三面光晕连通。只衰减直接光和墙面间接光，圆内深色字母仍来自真实阴影映射，不绘制或替换字母阴影。
- 左键/触摸拖动仅改变木雕的四元数，相机和场景固定，松手即停，无缩放、平移、自动旋转。场景只有一个 Reset 可见控件，520ms slerp 复位；支持减少动态效果和画布方向键操作。
- 按需渲染、像素比上限 1.75、桌面 2048²/窄屏初次加载 1024² 阴影、ResizeObserver、离屏/后台暂停及资源释放。
- `cd geb; npm install; npm run dev` 启动开发预览（默认 http://127.0.0.1:5173/geb/）；`npm test`、`npm run build`、`npm run preview` 用于验证和生产预览。此前 8767 静态服务器仍可预览构建后的入口。
- 构造、部署、文件结构与已知边界详见 `geb/README.md`。没有精确复刻封面，边缘保留体素切角；尚未跨设备实测 60 FPS。

## 实现方式

- 初期采用静态 HTML、CSS、原生 JavaScript ES modules，与现有 GitHub Pages 部署兼容，无需后端。
- 不引入 React、Vue 或全站统一 npm 构建流程；`/geb/` 已为木雕需求引入独立 Vite 工程。
- HTML/CSS 用于页面控件、规则卡片与导航；SVG 用于推导树、音符和二维图形；Canvas 用于大量运动对象与连续绘制。
- 确实需要三维空间或旋转视角时才使用 Three.js。
- Tone.js 是音乐播放、音符调度与合成的候选，自己的音符编辑和交互组件与播放层分开。
- 需要从 MusicXML 显示正式乐谱时，再考虑 OpenSheetMusicDisplay；简单音符编辑可自行使用 SVG 实现。
- 音频由用户点击等操作启动；妥善管理音频、动画和三维资源的生命周期。
- 只按实际需求引入库，每章仅加载需要的依赖和素材，首页不统一加载所有重型库。

```text
geb/
├── src/
│   ├── index.html                 # 首页源码
│   ├── home/                      # 首页脚本、样式和木雕场景
│   └── chapters/00-intro/
│       ├── index.html             # 人物介绍与三分页框架
│       ├── main.js
│       └── style.css
├── shared/geb.css                 # 通用主题、基础布局和导航
├── assets/model/                  # 模型与诊断文件
├── assets/app/                    # 生成的浏览器资源
├── scripts/
├── tests/
├── package.json / package-lock.json
├── vite.config.js
├── index.html                     # 生成的首页
├── chapters/00-intro/index.html    # 生成的章节页
└── dist/                          # 完整构建结果，不提交
```

只编辑 src/ 中的页面；首页专用模块在 src/home/，章节源码在 src/chapters/<编号-名称>/，每章包含 index.html、main.js 和 style.css。Vite 自动发现各章 HTML 入口，发布脚本同步首页、chapters/ 和 assets/app/；这些静态产物随源码提交。dist/ 包含所有已实现页面，可独立预览整个项目。发布脚本不自动清理历史产物，删除或改名页面时需检查旧发布文件。

第三方依赖统一使用 npm 和 package-lock.json 管理，由 Vite 打包为本地静态资源，不另建手动 vendor/。每章只导入自身所需依赖；shared/ 保留自行编写的跨页面代码，首页专用样式已移到 src/home/style.css。素材按需添加，记录来源与授权。
