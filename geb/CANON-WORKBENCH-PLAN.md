# 巴赫：卡农工作台 UI 设计

2026-11-06 首发曲目“两只老虎”已接入真实播放。工作台支持五声部、整小节拖动、独立混音、七档速度、循环、音画同步及离页暂停。第二声部默认从第 3 小节进入。

录音路径已支持固定节拍素材的七档离线变速、按需解码、共享音源、波形与歌词时间标注。录音准备说明见 `src/chapters/00-intro/bach/pieces/README.md`。已用合成测试音验证七档长度与音高，并测试录音共享解码和恢复偏移。其余曲目仍待确定可用素材，真实人声音质、歌词同步及非等速录音节拍对齐需按选定版本验收。

## 文案与页面风格

沿用哥德尔与埃舍尔分页的字号、间距、人物配色和“眉题 / 标题 / 简介”结构。

- 眉题：音乐 · 模仿与交织
- 标题：卡农
- 简介：卡农是一种以模仿为基础的复调音乐：一个声部先奏出或唱出旋律，其他声部依照一定的规则跟随。同一条旋律在不同时间展开，彼此交织，形成新的和声与层次。

简介只介绍音乐概念。工作台通过曲库选中态、音轨拖动把手、开始小节选择器、音量滑杆和明确的按钮名称表达操作方式，不写操作教程。

## 曲库与同曲多声部

- 曲库放在工作台顶部，桌面为四列，窄屏为两列，避免固定侧栏挤压时间轴。
- 候选名称暂列“保卫黄河”“两只老虎”“螃蟹卡农”“Dona Nobis Pacem”，最终曲目和版本待定。
- 选中一首曲目后，所有声部使用该曲目的拷贝。切换曲目时重置为两个声部，使用新曲目的默认进入位置和音量，并清除静音与独听状态。
- 默认两个声部，最多五个。添加按钮复制当前曲目到新声部，按该曲目设定的间隔比上一声部晚若干小节。达到五个时禁用按钮，旁边始终显示数量。至少保留一个声部，所有声部均可调整开始时间。

## 波形、音符与歌词

波形与音符是同一个音轨片段的两种视图，共用开始位置、时长、小节坐标和播放位置。

| 素材 | 默认显示 | 数据要求 |
| --- | --- | --- |
| 人声录音 | 波形 + 下方歌词行 | 录音的振幅包络、节拍/小节映射、歌词时间戳 |
| 音符旋律 | 音符条 | 音高、起拍与时值 |
| 同时有录音和音符数据 | 由曲目配置指定显示方式，歌词按数据自动展示 | 两类数据对应同一版本与同一段音乐 |

- 波形用于看到发声、停顿、乐句与动态，不承担显示音高的任务。
- 音符横向表示起拍和时值，纵向表示音高，不把录音的振幅当作旋律曲线。
- 歌词在片段底部单独成行；未来按真实时间戳定位，不强制一句歌词等于一小节。没有歌词数据时自动省略歌词行。
- 真实录音须先确定裁切段与第一小节锚点；有弱起、变拍或速度变化的版本需单独标记，不能简单把音频平均切成小节。
- 本 demo 的波形是程序生成的排版图形，音符是通用示例序列，歌词使用“歌词片段一”等占位文字；不对应真实作品。四小节长度、拍号也仅是布局测试数据。
- 波形 / 音符以及是否显示歌词均由曲目数据决定，不向用户提供属性切换控件；没有音符标注的人声录音不能直接切出虚构乐谱。

## 时间轴与声部控制

- 所有声部共用小节刻度，拍细分线在背景中呈现。
- 整个片段横向拖动，按完整小节吸附，不按单拍吸附；开始位置不得早于第 1 小节。
- 左右方向键与“开始：第 N 小节”选择器提供等价操作。
- 时间轴至少显示八小节，随片段最晚结束位置延长。向右拖动到边缘时可继续滚动，下拉框可选择当前时间轴末尾的下一小节。窄屏只有时间轴内部横向滚动，声部控制固定在左侧。
- 每个声部具有独立 0～100% 音量、静音、独听与删除。音量属于声部，不修改原始素材；独听可关闭并恢复原有静音状态。
- 拖动只影响开始时间，不改变片段内容、时长和局部速度。取消拖动恢复原位置，额外指针不参与操作。

## 整体调速

使用带刻度的速度选择条：0.50× / 0.75× / 1.00× / 1.25× / 1.50× / 1.75× / 2.00×，默认 1.00×。原生 range 的 step 为 0.25，拖动与键盘操作都只落在七个档位，当前数值实时显示。仅设置整体速度，无单声部速度。

选择离散档位的理由：易于重复比较，恢复原速明确，避免产生难以辨认和复现的任意倍率。

未来真实播放时，所有声部共享时间映射；调速改变整首音乐的秒数，不改变小节位置。人声应以保持音高的整体时间伸缩为目标，不能直接把升降调当作调速效果。具体音频处理方式待素材和音频层实现时验证。

## 原型阶段记录

- 曲库选中态及整体切换，由曲目自动确定波形 / 音符与歌词行。
- 增删声部与五声部上限、独立音量数值、静音和独听视觉状态。
- 真实的 UI 位置拖动预览、整小节吸附、键盘和选择器调整位置。
- 整体速度档位、循环按钮的选中状态。

播放不发声、不推进指针，点击后提示尚未接入音频。没有音频解码、素材下载、调度、混音、变速或逐字歌词高亮。界面标注“UI 预览 · 暂无音频”，避免把排版示意当作真实演奏。

## 开发计划与验收依据

按以下顺序交付，每轮都以可听或可操作的行为验收；先完成一首曲目的端到端体验，再扩充曲库。

### 1. 曲库数据与第一首真实素材

- 确定一首首发曲目、具体版本、可用谱本或单声部录音，记录来源与授权。优先验证一首旋律，再接一首带歌词录音；不一次制作所有候选曲目。
- 独立曲目配置记录 id、名称、素材类型、显示类型、拍号、小节锚点、音符数据或音频路径，以及可选歌词时间戳。编排状态只引用曲目 id，不复制素材。
- 区分有无人声、是否有歌词和显示方式；当前 demo 的 vocal 简化判断随后改为独立字段，避免把“有人声”等同于“有歌词标注”。
- 验收：真实长度、节拍和歌词与素材一致，所有示意数据只在 demo 中存在。

### 2. 统一编排与播放状态

- 提取纯状态模块，管理曲目、最多五个声部、进入小节、音量、静音、独听、全局速度、播放位置与循环。
- 音乐位置以拍存储，进入位置以小节换算成拍。固定速度素材通过 BPM 换算秒数；弱起、变拍和速度变化采用显式锚点表，不按音频总长均分。
- 建立 stopped / playing / paused / ended 状态转换。播放结束后重播从头；暂停保留位置；从头保留编排设置。
- 验收：增删、切曲与位置修改不丢失设置；边界与五声部上限有纯状态测试。

### 3. 真实播放与声部混音

- 点击播放后初始化音频。音符素材按事件调度合成音；录音只加载和解码一次，各声部共享素材并拥有独立播放实例与 GainNode，统一汇入主输出。
- 用 AudioContext 的时钟作为播放基准，预先调度短时间窗口，动画只读取音乐位置，不用 requestAnimationFrame 或普通定时器计算声音的播放时机。
- 暂停时记录位置并停止活动音源，恢复时重建相应位置的播放实例；音符长音需补足剩余时值。
- 声部音量与静音平滑改变增益，独听保留原静音状态。主输出预留多声部叠加的余量，检查五声部同时进入的音量。
- 验收：单声部和错时双声部真实可听，暂停续播、从头、静音与独听有效，再验证五声部。

### 4. 七档整体调速与循环

- 音符调速改变起音间隔与持续时间，保持音高；录音需要先验证保持音高的时间伸缩方案。
- 为人声在 0.50× 与 2.00× 的效果做独立技术验证，再决定浏览器端实时处理或离线生成七档文件。离线方案以包体和加载成本为取舍依据；不先引入未经验证的音频库。
- 所有声部共用倍率与时间映射。首版在结束拖动后提交新速度，保留当前音乐拍点并重新调度；拖动过程只更新数值，避免反复重建处理链。
- 循环边界取最后一个声部的真实结束位置；统一取消或重建后续事件，避免上一轮残留声音。
- 验收：七档速度、音高、切换位置和循环接缝正确，包含尾音跨边界处理。

### 5. 真实图形、歌词与拖动同步

- 波形峰值从实际音频离线生成并缓存，音符从同一播放事件数据绘制；停止使用示意图形。
- 歌词按时间戳映射到小节坐标，播放指针、当前音符和歌词高亮都由统一音乐位置驱动；速度变化不改变图形的小节位置。
- 保留整小节吸附、键盘和选择器操作。修改编排先暂停，再应用改动；补齐拖到边缘自动滚动、取消恢复和窄屏触摸操作。
- 验收：声音、指针与歌词同步，拖动后新进入位置准确，无重复或漏音。

### 6. 生命周期、错误与最终验收

- 切换人物、后台或页面退出时暂停或释放音频；返回不自动出声，保留可继续的位置。取消过期的加载请求和调度，防止快速切曲后旧素材覆盖当前选择。
- 增加加载、失败、重试状态，失败时不让播放指针假装推进。检查减少动态效果、键盘和读屏通知。
- 分别覆盖真实旋律与人声、七档速度、五声部、快速切曲、暂停续播、循环、离页返回和窄屏；使用听觉验收与有针对性的状态/调度测试。
- 更新素材来源、项目记忆及发布产物，再扩充其他曲目。

源码只修改 `src/`，`npm run build` 同步发布页面和本地资源。当前没有新增第三方依赖。
